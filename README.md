# TrustDoc AI

AI-Powered Digital Document Provenance, Forensic Verification & Trust Platform.

## Features Completed
- JWT RBAC Authentication (Admin, Issuer, Reviewer, Document Owner)
- Secure Upload & SHA-256 Fingerprinting
- AI Document Intelligence (OCR & Extraction simulation)
- Forensic Analysis (Risk Score, Trust Score)
- Cross-Document Consistency (Timeline checks)
- Immutable Registration & QR Generation
- Hash-Chained Audit Logs (Provenance)
- PDF Reports
